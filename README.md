# Card Design Gallery

A responsive web gallery showcasing various card design implementations using HTML, CSS, and JavaScript. The gallery features an intuitive navigation system and smooth transitions between different card designs.

## Features

- Clean and modern UI with dark themed navigation
- Smooth transitions between card designs
- Responsive layout that works across devices
- Easy-to-use navigation with highlighted active state
- 20 unique card design implementations
- Iframe-based preview system

## Technical Details

- Pure HTML, CSS and vanilla JavaScript implementation
- CSS Grid and Flexbox for layouts
- Custom button styling with hover effects
- Dynamic content loading through iframes
- Modular architecture for easy addition of new card designs

## Structure

The gallery includes various card designs:
- YouTube style cards
- Course cards
- Profile cards
- Animated cards
- Navigation components
- Table layouts
- And more...

## Usage

Simply open `index.html` in a modern web browser to view the gallery. Click the navigation buttons to switch between different card designs.

## Browser Support

Compatible with modern browsers that support:
- CSS Grid
- Flexbox
- CSS Custom Properties
- ES6 JavaScript
